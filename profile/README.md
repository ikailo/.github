# Ikailo Inc.

Ikailo is a Canadian research and development company in Whitby, Ontario. It builds Agience and Entroptics.

The code is published under the [Agience](https://github.com/Agience) organization:

- [Entroptics](https://github.com/Agience/entroptics): open-source signal analysis that reads structure from the data itself.
- [The Agience platform](https://github.com/Agience/agience-observe): signed, content-addressed information, run on your own machine.

Research briefs and papers: [ikailo.com](https://ikailo.com)
